# 物理模型与结果约定

两个程序采用同一条光路：

```text
输入面 z=-f → 空气传播 f → 有限口径薄透镜 z=0 → 观察面 z=f
```

加载像差时，相位屏位于输入面。透镜前只经过一段空气，保留完整复振幅传播和真实孔径截断。介质为空气，n=1。透镜采用近轴理想薄透镜，不需要材质、曲率等参数。

## 输入

- 波长单位 nm；项目约定可见光范围为 380–780 nm，范围外仍按输入计算并给出提示。
- 透镜直径、焦距及光束直径单位 mm。
- 光束尺寸定义在输入面，而不是透镜前；程序会传播到透镜前再截光。
- 高斯光直径为 1/e² 光强直径；均匀光为有限圆形顶帽直径。
- 加载前波前平坦；毫米级高斯光在远小于瑞利长度的传播距离内近似准直。
- 高斯光保留微弱尾部，不在 1/e² 半径处人为裁切。

## 传播和薄透镜

前段使用 Fresnel 角谱传递函数：

```text
H(fx,fy) = exp[-i*pi*lambda*f*(fx²+fy²)]
```

透镜透过函数为有限圆孔径乘二次相位：

```text
t(x,y) = A_D(x,y) * exp[-i*pi*(x²+y²)/(lambda*f)]
```

后段 Fresnel 积分与透镜二次相位解析合并，使用 CZT 在独立的微米级观察网格上求值，避免直接欠采样毫米口径上的透镜相位。计算全程保留绝对功率标度，解析输入功率归一为 1 W。

这仍是标量近轴模型。D/(2f)>0.2 时提示近轴误差可能显著，不宣称是高 NA 精确解。

## Zernike 系数

采用单位圆面积 RMS 归一化的实 Zernike 基底。m>0 用 cos，m<0 用 sin，使用 (n,m) 直接指定模式：

| (n,m) | 含义 |
| --- | --- |
| (1,1)、(1,-1) | x、y 倾斜 |
| (2,0) | 离焦 |
| (2,2)、(2,-2) | 两方向像散 |
| (3,1)、(3,-1) | 两方向彗差 |
| (3,3)、(3,-3) | 两方向三叶像差 |
| (4,0) | 初级球差 |

```text
phase = 2*pi*sum(coefficient_waves[j]*Z[j])
OPD   = wavelength*sum(coefficient_waves[j]*Z[j])
```

系数的绝对值是该项的 RMS（waves）。系数 1 对应 2π rad RMS，并不是每个点的相位都为 2π。固定 waves 系数时，波长变化不会改变加载相位，但对应的 nm 光程差会变化。模拟固定光程差时需设置 `coefficient_waves=光程差nm/wavelength_nm`。

归一化圆半径在输入面定义，与透镜孔径和光束尺寸独立。圆外 OPD=0，振幅仍正常通过；归一化圆不是光阑。圆边缘可能存在相位跳变，其衍射会参与计算。高斯入射不改变基底的面积归一化。

展示相位使用 `angle(exp(i*phase))`，范围 [-π,π]。RMS 根据未包裹相位计算。弱光区域仅在图中遮罩，不改变计算光场。

## 指标

纵向切面：XZ 固定 y=主峰在 z=f 平面的 y 坐标，横坐标为实际 x；YZ 固定 x=主峰在 z=f 平面的 x 坐标，横坐标为实际 y。两张切面沿相同 z 网格计算，使用同一个强度最大值作线性归一化，不逐个 z 平面归一化，也不跟随峰值移动。无像差程序只计算 XZ，有像差程序同时计算 XZ/YZ。切面中心列与轴向曲线在数值误差范围内一致。

- 横向 x/y FWHM：**固定 z=f 平面**的主峰截面半高全宽，不调焦。
- 轴向 FWHM：固定穿过 z=f 光斑主峰的横向位置扫描 z，求光强曲线的半高全宽。扫描只用于此曲线，不用来选择新观察面。
- 透过率：透镜孔径后功率除以孔径前功率。
- EE80：相对于全部透射功率的 80% 包围能量半径，不将有限图像视场的功率重新归一为 100%。

无像差圆对称光束的 x/y 宽度相同；有像差时分别报告。多峰时 FWHM 只描述所选主峰，找不到完整交点时返回 null，不外推数值。以上是聚焦光场指标，不直接替代任意相干成像系统的两点分辨判据。

透镜处均匀平坦波前的解析参考为 Rayleigh 横向距离 0.609835 lambda/NA、横向光强 FWHM 0.514497 lambda/NA、近轴轴向 FWHM 1.771786 lambda/NA²，其中 NA≈D/(2f)。有限前焦面光束经过传播后不一定满足该照明条件，因此不能强求其与这些系数完全相同。

## 数值精度

默认输入网格 768×768，观察面至少 257×257，轴向 121 点，展示焦斑在 513×513 网格重新求值。

`--grid-size`、`--image-samples`、`--axial-samples` 控制采样；`--window-mm` 控制输入窗口全宽；`--image-half-width-um` 和 `--axial-half-range-um` 分别控制横向半视场和轴向半范围。

输入窗口要覆盖传播后的光场，网格要分辨光束、孔径和相位。FFT 存在周期边界，功率守恒不能单独证明没有回绕。增大窗口时也需要保持足够的采样密度。强像差与极端参数应独立检查收敛；程序的诊断保存在 JSON 中。

验证覆盖高斯传播及截光、Airy 尺度、Zernike 正交归一、前后焦面 Fourier 对、离焦不被重新调焦补偿，以及两份独立程序在零像差时的一致性。
